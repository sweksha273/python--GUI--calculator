# python--GUI--calculator
So this is a basic GUI calculator app built from using the most versatile library of python that is tkinter, if you are new in coding and development then definitely you can start with this as it is a beginner friendly project.
We can use this calculator in any kind of phone and interfaces.
the motive of making this is just to learn the basics the concepts of python like functions,objects,classes,variables and loops.
first we have import a module or file from library tkinter, after importing we have defined CLASS name calculator and then in this class we have also defined several functions for performing the logical task.
Functions defined are:-
1)__init__
2)show
3)clear
4)solve
by giving parameter to each of the function out there we also defined some variables.
and then the class contains the the entire UI of the app like dimension,color,size and widgets position.
we have import functions like stringvar(),Entry(),Tk() and Button().
as we all know foe making the code easily readable comment statement has provided at each step of the code for better undersatnding.
And at the end mainloop has been used so as to start the application or for executing the code.
